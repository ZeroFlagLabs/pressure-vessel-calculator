# v2.0.0

Major interface redesign of the original Pressure Vessel Calculator v1.3, retaining its final stress equations and adopted allowable stress criteria.

- New compact interface, tolerance-aware geometry, automatic derived dimensions, and working/test pressure results.
- Inspect Results with equation substitutions, precision selection, and PNG report export.
- Settings with assumptions, references, licence details and stable GitHub release checks.
- Material yield and both pressures start at zero; derating starts at 1.00 and axial load at zero.
- Original engineering calculations and geometry selection unchanged from the tested v1.0.2 public build.

The short-lived public versions v1.0.0–v1.0.2 used an incorrect numbering convention. Version 2.0.0 supersedes them and continues the historical local v1.0–v1.3 sequence. This release changes version numbering only relative to v1.0.2.

Engineering scope and limitations are documented in the README and Engineering Scope document.

Download the Windows Portable ZIP, extract the single unsigned EXE and double-click it.
