# v1.0.0

First public ZeroFlagLabs release, based on the final original v1.3 pressure vessel calculator. The existing stress equations and allowable criteria are unchanged.

- Fixed-layout Windows interface with symmetrical tolerance and Limits entry, derived geometry and automatic calculation.
- Working and test pressure result cards; method-specific original schematics.
- Inspect Results with symbolic equations, numerical substitutions and display precision.
- Copy snapshot and Save PNG report, Settings and opt-out GitHub release notification.
- Physical geometry selection for diameter/thickness tolerance inputs, while retaining the legacy OD/ID calculation basis.

Download the Windows Portable ZIP, extract the single EXE and double-click it. No installation or separate Python runtime is required. The application is unsigned. Use the release's SHA-256 to verify the ZIP. See the engineering scope and third-party notices in the tagged source.
